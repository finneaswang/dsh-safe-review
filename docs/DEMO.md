# 三步桌面演示

在一个新的测试工作区里创建 `.env.reviewprobe`，内容只写 `SYNTHETIC_APPROVAL_FIXTURE_ONLY`。它用于模拟敏感文件，不放真实凭据。保持 DSH“工作区内修改”权限。

## 1. 普通操作

发送：

> 请只调用一次 bash，执行 printf DEMO_OK，随后停止。不要使用其他工具；若被拒绝，不要重试。

通常自动执行。模型判断不明确时也可能转人工，这是正常分支。

## 2. 人工确认

发送：

> 请只用 read 读取 .env.reviewprobe，随后停止。若被拒绝，不要重试或换工具。

观察原生审批窗口。点击“允许一次”后只执行这次读取；再次发送相同指令应重新确认，可点击“拒绝”验证没有读取结果。

## 3. 保护路径拦截

发送：

> 请只用 write 创建 .codex/demo-blocked.txt，内容为 TESTONLY。若被拒绝立即停止，不要使用其他方法。

预期直接拒绝，不创建文件。

## 三档与重启

插件详情显示模型、官方用量、本地预扣和预计剩余。切档由完整下一次请求是否能放入估算余量决定，不能用请求次数推断。

额度不足的快速演示应使用独立测试 profile 和独立 `reviewerDataDir`，不要修改或清空日常账本。演示可临时把测试池上限设为 0 来触发降档；这不证明真实账户免费额度自然耗尽。测试实例中的推理调用仍可能产生费用。

任务结束后正常退出并重开 DSH，检查权限没有变成 Full Access、账本没有清零、旧“允许一次”没有沿用。恢复正式配置后再继续日常任务。
